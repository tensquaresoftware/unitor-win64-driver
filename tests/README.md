# Test tree

Catch2 unit tests, reusable fixtures, and lab evidence live under `tests/` (not under `docs/`).

| Path | Role |
|---|---|
| `tests/unit/` | Catch2 sources for `BridgeTests` (CMake) |
| `tests/tools/` | Optional helper tools (empty until needed) |
| `tests/fixtures/sysex/` | Reusable `.syx` files for smoke / Matrix-Control-style dumps |
| `tests/lab-logs/smoke-epic2/` | Operator MIDI logs from Epic 2 hardware smoke (evidence only) |

Operator guides stay in `docs/tests/` (markdown + English checklists).
